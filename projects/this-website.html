Why I built it

A resume fits on one page, but the interesting part of a project usually doesn't: who needed it, what they were stuck on, and what changed once it worked. This site gives each project room for that longer version.

How it's made

  • Plain HTML and one CSS file, with no build step, so updating it takes minutes.
  • A warm palette of beige, olive green, terra cotta and acorn brown.
  • Layouts that work on phones, readable color contrast, and keyboard-friendly navigation.
  • Hosted free on GitHub Pages at alexandercranford.com.
